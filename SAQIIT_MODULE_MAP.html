All 13 audit findings verified fixed in the working tree

  • Guard RLS — is_guard_or_admin() now gates reads on vehicles, slots, allocations and entry logs.
  • Guard routing — the root screen checks isGuard before falling through to the resident view.
  • RPC bypass — the direct-insert fallback now fires only on Postgres 42883 (function missing), so the per-flat cap can't be sidestepped.
  • Exit logging — log_vehicle_exit checks society and caller before writing.
  • UI gaps — RC photo upload, bay maintenance/reserved toggles, bay delete, cap indicator and the blockless-society flat query are all in. The orphaned admin_vehicles_screen.dart is deleted.

What is left is process, not code: commit the working tree, open the PR against master, and run the 14 migrations in order on a clean Supabase project to confirm 11 → 12 apply on top of 01–10.
